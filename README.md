# 📍 GeoTrack HRMS

> **Employee Attendance Management System with Real-Time GPS Tracking**

GeoTrack HRMS is a modern, full-stack Human Resource Management System designed for tracking employee attendance with real-time GPS location validation, admin reporting, and employee management capabilities.

---

## 🚀 Features

### 👤 Employee Portal
- **Secure Authentication**: JWT-based authentication for employees and administrators.
- **GPS-enabled Check-In / Check-Out**: Automatically records employee geolocation (latitude, longitude, and location name) during clock-in and clock-out.
- **Real-Time Status**: Dashboard displaying live check-in status and today's work duration.
- **Attendance History**: View past attendance records with date range filters.
- **Profile Management**: View and update profile details.

### 🛡️ Admin Portal
- **Admin Dashboard**: Overview metrics including total employees, present count today, active check-ins, and department breakdowns.
- **Employee Management**: Register new employees, manage designations, departments, and credentials.
- **Attendance & Reports**: Generate and review attendance reports across departments and customizable date ranges.

---

## 🛠️ Tech Stack

- **Backend**: Python 3.10+, FastAPI, SQLAlchemy, SQLite (default) / MySQL, Passlib (bcrypt), PyJWT (python-jose).
- **Frontend**: React 18, Vite, Tailwind CSS, Axios, React Icons, React Hot Toast.
- **Containerization**: Docker & Docker Compose.

## 📦 Getting Started

### 1. Prerequisites
- Python 3.10 or higher
- Node.js 18 or higher
- npm or yarn

### 2. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Install dependencies
pip install -r requirements.txt

# Run database seed script (populates demo admin & employee accounts)
python seed.py

# Start backend server
uvicorn main:app --reload --port 8000
```

Backend server will run at: `http://localhost:8000`  
Interactive Swagger API Docs available at: `http://localhost:8000/docs`

### 3. Frontend Setup

```bash
# Navigate to frontend directory
cd frontend

# Install node packages
npm install

# Start Vite development server
npm run dev
```

Frontend application will run at: `http://localhost:5173`

## 📡 API Architecture Overview

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | API status & version | No |
| `GET` | `/api/health` | Service health check | No |
| `POST` | `/api/auth/register` | Register employee | No |
| `POST` | `/api/auth/login` | Obtain JWT token | No |
| `GET` | `/api/auth/me` | Current user profile | Bearer Token |
| `POST` | `/api/attendance/check-in` | Clock-in with GPS coords | Bearer Token |
| `POST` | `/api/attendance/check-out` | Clock-out with GPS coords | Bearer Token |
| `GET` | `/api/attendance/today` | Today's check-in status | Bearer Token |
| `GET` | `/api/attendance/history` | User attendance logs | Bearer Token |
| `GET` | `/api/admin/employees` | List all employees | Admin Token |
| `GET` | `/api/admin/reports` | Exportable attendance report | Admin Token |
